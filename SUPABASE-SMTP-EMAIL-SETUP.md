# Supabase SMTP Email Setup for Account Deletion

**Date:** August 7, 2026  
**Status:** Ready to configure

---

## 1. Install Required Package

First, install nodemailer (for sending emails via SMTP):

```bash
npm install nodemailer
npm install -D @types/nodemailer
```

---

## 2. Get SMTP Credentials from Supabase

1. Go to: https://supabase.com/dashboard/project/hbhahqephsndzjtqdzin
2. Click **Settings** → **Email** (in left sidebar)
3. You should see your SMTP configuration:
   - **Host:** (usually `smtp.supabase.co` or your mail provider)
   - **Port:** (usually `465` for TLS or `587` for STARTTLS)
   - **Username:** Your email address
   - **Password:** Your SMTP password

---

## 3. Configure Environment Variables

Add these to your `.env.local` (development) or `.env.production` (production):

```env
# App Configuration
NEXT_PUBLIC_APP_URL=https://codecoogs.com

# Email SMTP Configuration (from Supabase Settings)
SUPABASE_MAIL_HOST=smtp.supabase.co
SUPABASE_MAIL_PORT=465
SUPABASE_MAIL_SECURE=true
SUPABASE_MAIL_FROM_EMAIL=noreply@codecoogs.com
SUPABASE_MAIL_FROM_PASSWORD=your_password_from_supabase
```

**Where to find SMTP password:**
- Supabase Dashboard → Settings → Email → SMTP Password

---

## 4. Update Supabase Project Settings

Make sure your Supabase email sending is enabled:

1. Go to Settings → Email
2. Check that SMTP is configured
3. Note the sender email address (should be something like `noreply@yourdomain.com`)

---

## 5. Test Email Sending

Once configured, test the deletion flow:

1. Sign in as a test user

3. Click **Delete My Account**

## Troubleshooting

### Email Not Sending

**Check 1: SMTP Credentials**
- Verify credentials in `.env` match Supabase settings
- Check password is correct (not just copied wrong)

**Check 2: Environment Variables**
- Make sure variables are loaded: restart dev server
- Production: verify variables in deployment settings (Vercel, etc)

**Check 3: Logs**
- Check server console for error messages
- Look at Supabase project logs

**Check 4: From Email**
- Verify `SUPABASE_MAIL_FROM_EMAIL` is a valid sender email
- Some SMTP providers restrict sender domains

### Link Not Working

- Verify `NEXT_PUBLIC_APP_URL` matches your domain
- Check token is passed in URL: `/confirm-deletion?token=xyz`
- Ensure database records were created

### Email in Spam

- Check sender domain reputation
- Verify SPF/DKIM records if self-hosted
- Supabase typically has good deliverability

## Manual Testing Commands

To test if SMTP is working without the full app:

```javascript
// Test SMTP connection
const nodemailer = require('nodemailer');

const transporter = nodemailer.createTransport({
  host: process.env.SUPABASE_MAIL_HOST,
  port: process.env.SUPABASE_MAIL_PORT,
  secure: true,
  auth: {
    user: process.env.SUPABASE_MAIL_FROM_EMAIL,
    pass: process.env.SUPABASE_MAIL_FROM_PASSWORD,
  },
});

transporter.verify((error, success) => {
  if (error) {
    console.log('SMTP Error:', error);
  } else {
    console.log('SMTP Ready:', success);
  }
});
```
